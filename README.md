Abstract
Logic Relativity --- Unified Continuum (LR-UC) is a four-dimensional relativistic framework in which standard Einstein gravity is retained and the dark-matter sector is represented by a conserved, universe-filling relativistic continuum.
The continuum is described by three comoving scalar material coordinates,
[ \Phi{=tex}^A(x^\mu{=tex}),\qquad {=tex}A=1,2,3, ]
rather than by a fifth dimension or a direct fifth force.
The central action is
[ S=S_{\rm EH{=tex}}+S_b+S_{\rm UC{=tex}}+S_\Lambda{=tex}, ]
with the Einstein-Hilbert term providing ordinary GR and the continuum action depending on the material metric
[ B^{AB}=g^{\mu{=tex}\nu{=tex}}\partial{=tex}\mu{=tex}\Phi{=tex}^A\partial{=tex}\nu{=tex}\Phi{=tex}^B. ]
The continuum has a pressureless homogeneous branch,
[ \rho{=tex}{\rm UC{=tex}}\propto {=tex}a^{-3},\qquad {=tex}p{\rm UC{=tex}}=0, ]
so it supplies the cosmological cold-dark-matter sector, while the cosmological constant remains dark energy.
Nonlinear deformation is described by objective strain invariants. In spherical symmetry the theory admits an asymptotic
[ \rho{=tex}_{\rm UC{=tex}}\propto {=tex}r^{-2} ]
branch, implying
[ M_{\rm UC{=tex}}\propto {=tex}r ]
and approximately flat circular velocity.
The cosmological continuum density defines a natural acceleration scale
[ a_{\rm LR{=tex}}=c\sqrt{G\rho_{\rm UC,0}}{=tex}, ]
without introducing a separate acceleration constant for each galaxy. The nonlinear infrared response can generate MOND-like low-acceleration behavior while leaving the Einstein equations unchanged.
The same continuum is intended to provide one physical dark sector across cosmology, galaxy formation, halos, clusters and lensing.
The framework is deliberately parsimonious: no fifth dimension, no direct baryon-continuum fifth force, no galaxy-specific halo concentration/core/scale parameters, and no phenomenological RAR law treated as fundamental.
