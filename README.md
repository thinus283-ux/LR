Overview
Logic Relativity — Unified Continuum (LR-UC) is a four-dimensional Einstein-gravity framework in which the dark-matter sector is represented by a conserved relativistic material continuum described by three comoving scalar fields
[ \Phi^A(x^\mu), \qquad A=1,2,3. ]
The framework deliberately retains:
standard four-dimensional Einstein gravity;
ordinary baryons with minimal metric coupling;
one conserved universe-filling UC continuum;
the cosmological constant (\Lambda) as dark energy.
It does not introduce a fifth spacetime dimension or a fundamental direct baryon–continuum fifth force.
The central physical chain is
[ \boxed{ \text{baryons} \rightarrow \text{Einstein geometry} \rightarrow \text{UC organization/deformation} \rightarrow T_{\mu\nu}^{\rm UC} \rightarrow \text{Einstein geometry}. } ]
At the homogeneous level the same continuum behaves as cold dark matter. At galactic scales its nonlinear phase-space organization and collective displacement generate an effective low-acceleration response.
Important status statement: “closed” here means that the working equations and effective closure are explicitly specified. It does not mean that the remaining microscopic formation problem has already been solved. The unresolved formation quantities are deliberately marked YELLOW.
1. Theory in one page
Fundamental action
[ S=S_{\rm EH}+S_b+S_{\rm UC}+S_\Lambda ]
with
[ S_{\rm EH}= \frac{c^3}{16\pi G} \int d^4x\sqrt{-g},R, ]
and
[ S_{\rm UC}
-\int d^4x\sqrt{-g} \left[ \rho_0c^2b+W_{\rm def}(Q)+W_P(b) \right]. ]
The material metric is
[ B^{AB}
g^{\mu\nu} \partial_\mu\Phi^A\partial_\nu\Phi^B. ]
The conserved current is
[ J^\mu= \frac1{3!} \epsilon^{\mu\nu\rho\sigma} \epsilon_{ABC} \partial_\nu\Phi^A \partial_\rho\Phi^B \partial_\sigma\Phi^C, \qquad \nabla_\mu J^\mu=0. ]
Define
[ b=\sqrt{\det C}, \qquad \bar C=b^{-2/3}C, \qquad S=\frac12\ln\bar C, \qquad Q={\rm Tr}(S^2)\ge0. ]
The representative local deformation law is
[ W_{\rm def}
\mu_0q_0^2 \left[ \sqrt{1+\frac{Q}{q_0^2}}-1 \right], ]
with
[ \mu_0=4\times10^{-16}, \qquad q_0=10^{-3}. ]
The positive Planck-density term is a UV regulator only; it is not a bounce mechanism.
2. Cosmological branch
For homogeneous FLRW,
[ b=a^{-3}, \qquad Q=0, ]
giving
[ \boxed{ \rho_{\rm UC}\propto a^{-3}, \qquad p_{\rm UC}=0. } ]
The background equation is
[ H^2= \frac{8\pi G}{3} (\rho_r+\rho_b+\rho_{\rm UC}) + \frac{\Lambda c^2}{3}. ]
The present UC density gives the derived acceleration scale
[ \boxed{ a_{\rm LR}
c\sqrt{G\rho_{\rm UC,0}}
1.1746\times10^{-10}\ {\rm m,s^{-2}}. } ]
3. Galactic ontology
The galactic halo is not a separate substance and is not a static shell.
It is the nonlinear organization of the same cosmological UC continuum:
[ \boxed{ \text{cosmological UC} \rightarrow \text{capture/organization} \rightarrow \text{UC self-gravity} \rightarrow \text{energy + angular-momentum sorting} \rightarrow \text{extended orbital population} \rightarrow \text{cosmological background}. } ]
Angular momentum is not an outward force. Energy and angular momentum jointly determine the final phase-space occupation.
The outer halo is required to fade smoothly into the background.
4. Weak-field / phase-space representation
The exact continuum flow map gives
[ f(\mathbf x,\mathbf v,t)
\int d^3q,\rho_0(\mathbf q) \delta^3[\mathbf x-\mathbf X(\mathbf q,t)] \delta^3[\mathbf v-\dot{\mathbf X}(\mathbf q,t)]. ]
In the galactic weak-field limit,
[ \partial_tf+\mathbf v\cdot\nabla_xf -\nabla\Psi\cdot\nabla_vf=0 ]
and
[ \nabla^2\Psi= 4\pi G(\rho_b+\rho_{\rm UC}). ]
The halo therefore has a genuine distribution
[ f(E,L_z,L), ]
not merely a fitted radial density law.
5. Spherical deformation
For
[ r=r(R), ]
[ b=\frac{R^2}{r^2r'}, ]
and
[ Q= \frac23 \left[ \ln\left(\frac{r}{Rr'}\right) \right]^2. ]
The principal-stress difference is
[ p_r-p_t=2\delta W_Q. ]
A mathematically admissible scale-free branch is
[ r=CR^3, ]
which gives
[ \rho_{\rm UC}\propto r^{-2}. ]
Consequently,
[ M_{\rm UC}\propto r, \qquad g_{\rm UC}\propto r^{-1}, \qquad V_c\simeq{\rm constant}. ]
Crucial interpretation: the (r^{-2}) branch is an intermediate nonlinear regime. It cannot continue to infinity because its mass diverges.
6. Similarity scaling and BTFR
Define
[ r_=\sqrt{\frac{GM_b}{a_{\rm LR}}}, \qquad v_=(GM_ba_{\rm LR})^{1/4}. ]
If the nonlinear formation solution generates
[ \frac{M_{\rm UC}(<r)}{M_b} \sim A\frac r{r_*}, ]
then
[ \boxed{ V_f^4=A^2GM_ba_{\rm LR}. } ]
Define
[ \chi_{\rm form}=A^2. ]
The parameter-free microscopic target is
[ \chi_{\rm form}\rightarrow1. ]
The present empirical (\chi_g) values are treated as effective formation-state summaries until this eigenvalue is derived dynamically.
7. Infrared collective response
The long-wavelength polarization is a coarse-grained observable of the same continuum,
[ P_{\rm UC}
\bar\rho_{\rm UC}(\xi_\ell-\xi_L). ]
Define
[ p=\frac{4\pi GP_{\rm UC}}{a_{\rm LR}}. ]
The working convex infrared energy is
[ \boxed{ W_{\rm IR}
\frac{a_{\rm LR}^2}{4\pi G} \left[ \frac{p^2}{2} +\frac{p^3}{3\chi} +\frac{\alpha_{\rm IR}p^5}{5\chi} \right]. } ]
Its constitutive equation is
[ \boxed{ g=g_N+a_{\rm LR}p, \qquad \frac{g_N}{a_{\rm LR}}
\frac{p^2+\alpha_{\rm IR}p^4}{\chi}. } ]
The physical solution is
[ p^2= \frac{ \sqrt{1+4\alpha_{\rm IR}\chi g_N/a_{\rm LR}} -1 }{ 2\alpha_{\rm IR} }. ]
The sector is convex and the physical branch is unique.
8. Analytic limits
Deep infrared:
[ \boxed{ g\simeq\sqrt{\chi a_{\rm LR}g_N}. } ]
High acceleration:
[ \boxed{ \frac{g-g_N}{g_N} \sim \left( \frac{\chi}{\alpha_{\rm IR}} \right)^{1/4} \left( \frac{a_{\rm LR}}{g_N} \right)^{3/4} \rightarrow0. } ]
For a spherical baryon-dominated source,
[ g_{\rm P}
\frac{\sqrt{\chi GM_ba_{\rm LR}}}{r}, ]
so
[ \boxed{ \rho_{\rm P}
\frac{\sqrt{\chi GM_ba_{\rm LR}}}{4\pi Gr^2} } ]
and
[ \boxed{ V_f^4=\chi GM_ba_{\rm LR}. } ]
9. Finite halo mass: no hard cutoff
The actual galaxy must satisfy
[ \rho_{\rm UC}
\rho_{\rm UC,0}+\delta\rho_{\rm UC}, ]
with
[ \delta\rho_{\rm UC}\rightarrow0 ]
and
[ \boxed{ 4\pi \int_0^\infty [\rho_{\rm UC}-\rho_{\rm UC,0}]r^2dr <\infty. } ]
The desired radial structure is therefore
[ \boxed{ \text{inner nonlinear} \rightarrow r^{-2}\text{ intermediate} \rightarrow \text{phase-space transition} \rightarrow \rho_{\rm UC,0}. } ]
No (r_{\rm cut}) is introduced.
A weak-binding population
[ \delta f\propto\mathcal E^n ]
gives
[ \delta\rho\propto\psi^{n+3/2}. ]
For a Kepler-like tail, finite excess mass requires
[ n>\frac32. ]
A finite escape/turnaround separatrix instead gives a smooth vanishing law
[ \delta\rho\propto(r_{\rm tr}-r)^{n+3/2}. ]

14. Formation status
The project does not currently claim that the nonlinear formation calculation has derived the galaxy halo.
Existing formation tests found:
no converged universal (r^{-2}) attractor in the spherical collapse benchmark;
no robust flat-(V_c) attractor in the 4096-particle (48^3) screening;
unacceptable angular-momentum drift in the exploratory (64^3) run.
These are retained as negative diagnostics.
A rotating-potential DOP853 test did verify the mechanics identity
[ E_J=E-\Omega_pL_z ]
with maximum Jacobi drift (\sim4.4\times10^{-6}), showing that a rotating potential can exchange (L_z) while preserving the correct Jacobi invariant.
The decisive unresolved task is therefore:
[ \boxed{ f_{\rm cosmological} \rightarrow f(E,L_z,L) \rightarrow \rho_{\rm UC}(r) \rightarrow r^{-2}\text{ intermediate regime} \rightarrow \text{smooth finite-mass transition}. } ]
15. Phase-space control benchmark
A lowered-isothermal control calculation with (W_0=16) produces:
finite excess mass;
a near-(r^{-2}) region spanning (\sim1.03) dex;
near-flat (V_c^2);
near-separatrix density exponent (2.534), close to the analytic (5/2) result for (\delta f\propto\mathcal E).
This benchmark is deliberately not promoted into the LR-UC ontology. Its purpose is to prove that the required outer-transition architecture is numerically coherent before testing whether the microscopic LR-UC dynamics can generate it.

21. Research philosophy
The working rule is
[ \boxed{ \text{derive first} \rightarrow \text{solve numerically} \rightarrow \text{compare with data} \rightarrow \text{calibrate only justified nuisance quantities} \rightarrow \text{retest}. } ]
A failed numerical realization is retained as a failed test.
A calibration parameter is not automatically promoted to a fundamental constant.
A mathematically admitted profile is not automatically assumed to be dynamically selected.
A successful effective fit is not automatically claimed to be a first-principles derivation.
That distinction is central to the credibility of the repository.
